## JARVIS – lokaler Assistent für den Windows-PC

Das Projekt liegt im Ordner [`jarvis/`](jarvis/). Installation ohne Adminrechte: Repository als ZIP
herunterladen (*Code* → *Download ZIP*), entpacken (z. B. nach `C:\JARVIS-Setup`, nicht in einen
OneDrive-Ordner) und im Unterordner `jarvis` doppelt auf `Install.cmd` klicken.

Alle Schritte, Firewall, Tailscale und Fehlerbehebung: [jarvis/README.md](jarvis/README.md).
